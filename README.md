# 수능 백지도 확장 (`euclidraw/white-map-extension`)

한국 수능·평가원 지리 양식의 **백지도(`diagram.white-map.map`)**를 Alid 캔버스 도형, 100% 순수 벡터 정적 SVG 출판, 백지도 스튜디오 패널, 코파일럿 승인 도구(`workspace.tools`)로 제공하는 공식 외부 저장소 확장입니다.

![수능 백지도 5종 프리셋 SVG 미리보기](docs/map-presets.svg)

## 주요 기능

- **특정 지역 중심 백지도 & 50m 오프라인 내장 GIS**:
  - 태평양 중심 세계, 동아시아·오세아니아, 중국 동북 3성, 한반도, 덴마크·독일(페마른벨트), 유럽 등 12종 지역 프리셋과 `Mercator`, `Natural Earth`, `Conic Equal-Area`, `Equirectangular` 투영법을 지원합니다.
  - 해안선(실선), 국경선(파선), 성·도 행정경계(점선), 주요 하천(361개 선 피처, 한강·남한강·낙동강 포함), 호수, 적도(`0°`) 눈금을 오프라인으로 즉시 렌더링합니다.
- **확대 시 현재 범위의 벡터 타일 우선 로딩**:
  - 지도 내부 배율이 1800 이상일 때 **상세 타일**을 켜면 OpenFreeMap의 XYZ 벡터 타일로 해안선·섬·호수·하천을 표시합니다. 화면 범위와 겹치는 타일만 중앙부터 요청하며, 팬·줌이 멈추면 새 범위를 불러옵니다. 한국 행정 레이어를 켜도 바탕 지도의 해안선은 바뀌지 않습니다. 로딩 중이거나 네트워크가 끊기면 기본 지도가 남습니다. 타일은 세션 메모리 전용이며 JSONL에는 표시 여부만 기록됩니다.
  - 호수 토글은 호수·연못 면, 하천 토글은 수로 중심선과 넓은 강의 면을 표시합니다. 상세 타일의 표시 범위에 하천 정보가 없으면 내장 하천선을 사용합니다. 원자료와 축척에 따라 작은 지류는 생략될 수 있습니다.
- **더블클릭 지도 프레임 탐색**:
  - 백지도 프레임 안을 **더블클릭**하면 캔버스의 드래그·줌인아웃을 가로채 지도 프레임 내부에서 직접 팬(드래그)과 커서 기준 휠 줌을 수행합니다. `Shift+클릭`으로 국가·행정구역 강조를 토글할 수 있으며, `Esc`나 바깥 클릭 시 단일 Undo로 커밋됩니다.
- **수능 인쇄 스타일 5종 & 안전 `--map-*` 커스텀 CSS**:
  - 영문·숫자는 번들된 **CMU Serif**, 한글은 **Pretendard**를 사용합니다.
  - 단색 명암, 사선 빗금, 교차 빗금, 점묘(`stipple`), 이중선 경로(해저터널/철도), 수도 이중원(`◎`), 도넛 지점 마커, 위치 소지도 인셋, 지시선 라벨을 지원합니다.
  - 선택 시 범례 박스·위치 소지도에 **점선 러버 밴드와 이동 기즈모**, 지시선 라벨에 **기준점(앵커)·라벨 양끝 핸들과 더블클릭 인라인 텍스트 수정**을 제공합니다.
- **커스텀 GIS 매핑 & 인라인 레이어 편집**:
  - `.geojson` / `.topojson` / `.csv` **파일 드래그 앤 드롭(또는 파일 선택)** 및 텍스트 붙여넣기로 사용자 영역·경로·지점을 추가하고, 목록에서 표시 여부·이름·색상·빗금/선종/마커를 즉시 인라인 수정할 수 있습니다.
  - 작업 내역이 있는 지도에서 5종 수능 예제 프리셋을 누르면 **새 백지도로 추가 / 현재 지도에 덮어쓰기**를 먼저 확인해 실수로 기존 작업이 지워지지 않습니다.

- **Props 패널 정보 위계 구성 & 범례 항목 이름 편집 (`inspectorFor`) & 상단 고정 `.stem-toolbar`**:
  - 자주 쓰는 **수능 인쇄 스타일 · 기본 레이어 · 범례/위치 소지도** 섹션은 상단에 펼쳐 두고, **시점 좌표 미세조정 · 세부 색상 · 고급 CSS** 섹션은 기본 접힘(`sectionCollapsed`)으로 배치했습니다.
  - 또한 속성(Props) 창 내부 하단에 **`범례 항목 이름` 섹션(`inspectorFor: 'diagram.white-map.map'`)**이 자동으로 표시되어, 백지도 탭으로 이동하지 않고도 각 범례 항목의 기호 미리보기를 보며 **항목 이름 변경 및 개별 표시/숨김**을 바로 처리할 수 있습니다.
  - 백지도를 선택하거나 탐색 중일 때 화면 상단 중앙(`left: 50%; top: 12px`)에 **고정 가로 Hover Tooltip 툴바**와 상태 안내 행이 나타나 **지역 강조(A/B/C/D 슬롯 · 단위 선택 · 호버 윤곽선 미리보기)**, **지시선 라벨 추가/더블클릭 수정**, **지점 마커 배치**, **경로 그리기·분포 영역 다각형 그리기(실시간 고스트 미리보기 · `Backspace` 한 점 취소)**, **국경·하천·범례·인셋 토글**, **자동 상세화(Auto-LOD) 토글**을 바로 사용할 수 있습니다.

## 기준 좌표계: WGS 84 (EPSG:4326)

지도 데이터는 한국 행정경계 원본 GeoParquet의 CRS와 같은 **WGS 84 지리좌표계**를 사용합니다. GeoJSON 및 앱의 배열 순서는 **[경도, 위도]**, 단위는 **도(°)**입니다. 예: 서울시청 부근 `[126.9780, 37.5665]`. EPSG 정의의 공식 축 순서(위도, 경도)와 혼동하지 마세요. 화면의 메르카토르 등은 이 좌표를 평면에 그리는 **표시 투영법**이지 저장 좌표계가 아닙니다.

- **한국 시·도·시·군·구**: 같은 행정경계 자료에서 추출합니다. 행정경계와 강조는 바탕 지도의 육지 위에만 그립니다.
- **세계 해안선·국경·하천·호수**: Natural Earth와 world-atlas의 경위도를 그대로 사용합니다. 좌표계가 같아도 축척, 조사 시점, 단순화 방식까지 같아지는 것은 아닙니다. 50m/10m는 1:5천만/1:1천만 축척이지 미터 단위 위치 정확도가 아닙니다.
- **외부 레이어**: 백지도 탭 → 커스텀 GIS 임포트 → 원본 좌표계에서 EPSG:5179(국가통합좌표계)를 선택하면 X(동쪽), Y(북쪽) 미터 좌표를 WGS 84로 변환해 저장합니다. 자동은 파일의 CRS 선언을 우선하고, 선언이 없으면 경위도로 간주합니다. 다른 좌표계는 GIS 도구에서 먼저 재투영하세요.

## 대한민국 시·도와 시·군·구

지역 라이브러리에서 **한반도**를 선택한 뒤 **Props → 기본 레이어**에서 **대한민국 시·도 경계**(굵은 실선)와 **대한민국 시·군·구 경계**(가는 점선)를 독립적으로 켤 수 있습니다. 시·군·구만 켜도 각 구역이 구분되며, 둘 다 켜면 시·도 경계가 실선으로 강조됩니다. **지역 강조** 또는 탐색 중 **Shift+클릭**은 보이는 가장 작은 단위를 선택합니다. 백지도 탭의 **강조 그룹**에서는 시·도(2자리)와 시·군·구(5자리)를 따로 검색해 색·무늬와 범례 이름을 지정합니다.

2026-10-01 기준 16개 시·도, 256개 시·군·구(일반구 포함)입니다. 육지와 해안선은 행정 레이어와 관계없이 현재 기본 지도 또는 상세 타일을 따릅니다. [자료 출처](docs/third-party-notices.md#대한민국-시군구-경계)

## 저장 공간 경고가 뜨면

현재 탭을 닫기 전에 **파일 → 내보내기… → 문서와 이미지**로 백업하세요. 이미지가 없으면 **문서만**도 가능합니다. 두 JSONL 형식 모두 사용자가 추가한 GIS 레이어와 라벨은 보존하지만 새 베이크 결과물은 담지 않습니다. 다운로드된 파일을 확인한 뒤 확장을 업데이트하세요. 브라우저 데이터를 지울 필요는 없습니다.

v0.2.6에서 기존 문서를 열면 편집 가능한 지도의 이전 베이크 객체도 `true`로 바꿉니다. 이전 백업 파일과 CRDT 이력은 소급 삭제하지 않습니다. SVG는 내보낼 때 준비된 해상도를 사용하며, 오프라인으로 다시 열면 기본 지도만 표시됩니다. 이 변경이 호스트의 브라우저 저장 한도를 늘리지는 않습니다.

## 설치 및 개발

Alid 워크벤치의 **확장 관리 → GitHub 저장소 설치**에 다음 저장소를 입력하세요.

```text
euclidraw/white-map-extension
```

로컬 개발 및 검증:

```bash
pnpm install
pnpm dev
pnpm test
pnpm check:dist
pnpm test:explore
pnpm test:host
```
